# Episode 工作台重构与汉化设计规范

## 目标
重构 `episode` 工作台 (`[episodeNumber].vue`) 的前端代码，使其视觉表现完美符合 `DESIGN.md` 中定义的类 Figma 极简黑白高级美学。同时，结合系统的中文环境，将界面中所有的英文文本深度汉化，此过程在保留原有的数据结构和基础交互逻辑的前提下进行。

## 核心准则
1. **应用 Figma 美学**：全面使用自定义的几何特征（50px药丸形状与圆形），极致的黑白界面配合部分毛玻璃质感（`rgba(0,0,0,0.08)`），以及 `DESIGN.md` 中强制要求的负间距排版。
2. **全面深度汉化**：将 `episode` 界面中面向用户的所有英文字符串修改为影视/动画制作环境下的专业简体中文术语。
3. **无损视觉重构**：保留原有的功能和整体布局（顶部工具栏、左侧图层面板、中部分镜画布、右侧属性面板）和变量绑定，仅仅做表现层（CSS class、内联样式、静态文本内容）的修改。

## 详细实施方案

### 1. 排版与间距 (Typography & Spacing)
- 为标准的正文与次要文本应用负间距样式（推荐使用内联形式 `-0.14px` 或 `tracking-tight` 等原子类），以对齐 Figma 的排版高级紧凑感。
- 剥离通用的大写标题排版，在关键标签上强制使用 `mono-label` 包装。
- 中文内容复用全局字重体系，并着重体现出文字级别的层级关系。

### 2. 几何与聚焦状态 (Geometry & Focus Outlines)
- 将全部原有的方形按钮与输入框调整为药丸状（Pill-shaped）组件：
  - 核心/通用按钮：全局应用 `rounded-[50px]` 进行替换。
  - 图标操作按钮：全部改为 `rounded-full` 圆形 (50%)。
- 全局调整所有的交互控件（Tabs、Buttons、Inputs）的聚焦点亮（Focus/Active）状态，移除光晕或实线边框，强制替换为 `dashed 2px` 的签名式虚线边框。

### 3. 色彩与留白 (Color & Chrome)
- 剔除现有代码中的所有写死的彩色类名（如 `bg-blue-600`, `text-blue-500`, `border-gray-200`, `bg-green-500` 等）。
- 全局贯彻 纯黑 (`#000000`) 和 纯白 (`#ffffff`) 的颜色双元结构。
  - 主动作：纯黑底色，纯白文字。
  - 弱化动作：纯白底色，纯黑文字或无底色。
  - 悬停与次要背景：对于暗色界面使用透明质感 `rgba(0,0,0,0.08)`，如果有彩色的主视觉图，则在其上方使用 `rgba(255,255,255,0.16)`。

### 4. 汉化文本映射指南 (Localization Mapping)
本次重构将会替换以下 `[episodeNumber].vue` 的核心英文单词为中文：
- **顶部工作流 Tabs**：
  - `1. Script` -> `1. 剧本`
  - `2. Extract` -> `2. 角色解析`
  - `3. Cast` -> `3. 选角配置`
  - `4. Breakdown` -> `4. 镜头拆解`
  - `5. Production` -> `5. 生成制作`
- **左侧图层与导航节点**：
  - `RAW MATERIAL` -> `原始素材`
  - `REWRITTEN SCRIPT` -> `改写剧本`
  - `Characters` -> `登场角色`
  - `Scenes` -> `场景列表`
  - `Voice Casting` -> `配音设定`
  - `Storyboards` -> `分镜序列`
- **画布交互栏按钮与标题**：
  - `Save Raw Material` -> `保存原始素材`
  - `Extract Entities` -> `提取实体信息`
  - `Auto Assign Voices` -> `自动分配匹配声线`
  - `Breakdown AI` -> `AI 分镜拆解`
- **属性面板与生成状态 (Inspectors & Placeholders)**：
  - `Character Properties` -> `角色属性`
  - `Selected Voice` -> `选择声线`
  - `Action / Narrative` -> `镜头动作 / 旁白`
  - `Generate Frame` -> `生成首尾帧`

## 验收标准
- 生成图片之前，整个界面看起来像是一个完全黑白的极简专业设计工具。
- 交互元素的虚线边界清晰可见并符合操作直觉。
- 没有因为文本汉化而产生任何 Vue 插值或条件渲染相关的报错。
- 原有的全流程页面交互功能完全不受影响。
