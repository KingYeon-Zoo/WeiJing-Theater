# Settings Page Color Palette Redesign

## 项目背景 (Context)
当前的设置页面 (`frontend/app/pages/settings.vue`) 采用了黑色全屏背景与白框容器的布局结构。为了更紧密地贴合项目 `DESIGN.md` 中定义的具有强烈视觉冲击力的 "纯黑白极简组件 + 绚烂多彩画布 (Figma 风格)" 设计语言，我们需要对该页面的宏观配色与细节材质进行深度重组。

## 目标 (Objective)
通过将深色死板的背景切换为动态色彩渐变，配合极限对比度的实体纯白控制面板，重构出一个同时兼顾设计工具活力感与专业面板严谨性的设置中心。

## 视觉架构设计 (UI & Visual Architecture)

### 1. 页面大背景 (Colorful Canvas)
- **视觉层**：移除掉目前的 `var(--black)` 背景。
- **色彩设计**：引入从 `DESIGN.md` 提取的特征性多色渐变（电光绿、亮黄、深紫和热粉色混合）作为设置页面的满铺背景层。
- **目标**：以高度饱和的大面积色彩，强化这是一个充满创造力的现代化 AI 桌面端工具。

### 2. 容器与卡片材质 (Solid White Containers)
- **卡片底色**：所有的功能承载区（包括 `.settings-container`，`.preset-card`，`.config-table` 等）将严格使用 100% 不透明度的纯白色 (`#ffffff`)。
- **质感**：杜绝使用毛玻璃或半透明材质。实体白色提供了完美的信噪比，保证系统配置、API Key输入框等信息具有绝对的清晰度和可读性。
- **层级区分**：通过干净的微型黑色投影或是精确的 1px 黑边框（区别于此前的浅灰边框）来突出层级和悬浮感。

### 3. 内部 UI 控件重构 (Colorless Chrome)
- **强制黑白**：在设置容器内部，坚守“纯正无彩色”原则。原有的标签 (`tag-success`, `tag-accent`) 和提示色将被解构并映射到仅有纯黑、纯白以及过渡灰度的极致黑白灰系统中。
- **统一按钮几何**：页面的主要操作按钮和选项卡均使用 50px 极致圆角 (Pill)。
- **操作反馈**：激活态和焦点状态强制应用 Figma 的 `dashed 2px` 虚线框交互规范。没有任何多余的色彩介入选项变化之中。

## 修改范围 (Scope of Changes)
- **目标文件**：`frontend/app/pages/settings.vue` 的 CSS `<style>` 作用域及部分 Vue Class 绑定。
- **无破坏性重构**：该改变只针对于外观视觉、CSS 类和少量的 DOM 嵌套，以确保设置页面的核心状态与功能维持 100% 结构稳定。
