# 剧本结构拆分

## 核心规则

- 先找冲突转折，再决定场景切分。
- 一场只承担一个明确叙事目的：铺垫、冲突、揭示、反转或收尾。
- 先保证因果连续，再优化台词顺口。

## 推荐顺序

1. 从原文中标出关键动作和关键对白。
2. 按地点或时间变化切场；没有明显变化时，按冲突节拍切场。
3. 每场保留一个画面核心和一个情绪核心。
4. 收尾要给下一步提取角色/场景留清晰信息。
